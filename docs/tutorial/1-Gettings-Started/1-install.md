# Installing

**LaTeX Math** is as simple to install as any other Obsidian plugin.
Just press `Browse` in Obsidian's `Options (⚙️)> Community plugins` menu and search for `LaTeX Math`.

<a href="https://obsidian.md/plugins?id=latex-math" target="_blank"> Alternatively click this text to automatically open the plugin page in your Obsidian app. </a>

If you have not yet enabled community plugins, make sure to do this, as you will otherwise not be allowed to install the plugin.

Once you have located the **LaTeX Math** plugin, select it and press the highlighted `install` button.

> [!note] Note: Install Speed
> LaTeX math is somewhat *larger* than most other Obsidian plugins,
> so the installation, specifically the downloading part, may take a bit longer than usual.

Finally, once installed, make sure to press the `enable` button, and you will then be all set up with the **LaTeX Math** plugin!
